### Не знаешь, с чего начать? Короткий план по шагам

Если страшно и непонятно, с чего подойти к проекту — просто иди по этим шагам.

---

#### 1. Инициализируй проект

1. Создай папку проекта, открой её в редакторе.
2. В терминале выполни:

    go mod init `название проекта`
    go get github.com/gin-gonic/gin

---

#### 2. Подними самый простой сервер

1. Создай файл `cmd/api/main.go`.
2. Добавь минимальный код с gin и эндпоинтом `GET /ping`, который возвращает JSON:

    {"status":"ok"}

3. Запусти сервер и проверь в браузере/Postman, что `/ping` работает.

> На этом этапе у тебя уже есть живой backend — это важно почувствовать.

---

#### 3. Добавь первых пользователей

1. Пока можно писать всё в `main.go` (потом разнесёшь по слоям).
2. Опиши `type User { ... }` и хранилище:
   - Например, `var users = []User{}` или `map[id]User`.
3. Сделай эндпоинт `GET /api/v1/users`, который возвращает текущий список пользователей (сначала пустой).

Уже можно получить настоящий JSON-массив из своего сервера.

---

#### 4. Реализуй регистрацию пользователя

1. Сделай `POST /api/v1/register`, который:
   - принимает `username` из JSON;
   - генерирует `id` (счётчик или uuid);
   - добавляет пользователя в `users`.
2. Сценарий для проверки:
   - отправь `POST /api/v1/register`;
   - затем `GET /api/v1/users` — увидишь нового пользователя.

Теперь у тебя есть простой, но рабочий функционал регистрации.

---

#### 5. Подключи посты и лайки (минимально)

1. Добавь `Post` и in-memory хранилище постов.
2. Реализуй эндпоинты:
   - `POST /api/v1/posts` — создать пост;
   - `GET /api/v1/posts` — получить список постов;
   - `POST /api/v1/posts/{id}/like` — увеличить счётчик лайков для поста  
     (повторный лайк того же юзера не должен увеличивать счётчик).

3. Проверь полный сценарий:
   - зарегистрировать пользователя → создать пост → поставить лайк → убедиться, что лайк считается.

---

#### 6. Когда всё работает — разнеси по слоям

Когда базовый функционал живёт и проверен руками:

- перенеси сущности в `internal/domain`;
- бизнес-логику в `internal/app` (сервисы);
- HTTP-хендлеры и роутер в `internal/infra/http`;
- in-memory хранилище в `internal/infra/storage/memory`;
- точку входа оставь в `cmd/api/main.go`.

Рефакторить всегда проще, когда у тебя уже есть рабочий скелет приложения.
